# Laboratorio-Yahtzee2
Objetivo Principal Comprender y aplicar el método de Montecarlo en una aplicación que permita su ejecución y explotación de los resultados aleatorios obtenidos mediante la simulación del juego Yahtzee clásico con 2 jugadores. Simulación Estocástica Implementar lanzamientos aleatorios de dados.

## Implementación en Python

Se agregó una versión en Python que simula el juego Yahtzee con 2 jugadores, respetando el máximo de 3 lanzamientos por turno, bloqueo de dados y cálculo de las 13 categorías de puntuación.

### Cómo ejecutar

```bash
python3 yahtzee.py
```

Para una simulación automática:

```bash
python3 yahtzee.py --auto
```
